# 🧵 Threads Clone

A full-stack social media application inspired by Threads, built with **Node.js**, **Express.js**, **GraphQL**, **Apollo Server**, and **PostgreSQL**. This project is part of my journey to becoming a Full Stack Developer and focuses on building a scalable, API-driven application using modern web technologies.

## 🚀 Overview

Threads Clone allows users to create profiles, share posts, interact with other users, and engage in social conversations. The application leverages GraphQL for efficient data querying and PostgreSQL for robust relational data management.

This project helped me gain hands-on experience in designing GraphQL schemas, building secure APIs, managing database relationships, and implementing real-world backend architecture.

## ✨ Features

- User registration and authentication
- JWT-based authorization
- Create, edit, and delete threads
- User profiles
- Follow and unfollow users
- View personalized feeds
- Like and comment on threads
- GraphQL API powered by Apollo Server
- PostgreSQL database integration
- Modular and scalable backend structure
